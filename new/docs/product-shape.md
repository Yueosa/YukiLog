# 产品形态

## 公开导航

- 首页
- 文章
- 动态
- 友链
- 搜索

标签、分类和时间归档都属于文章筛选，不占用独立导航入口。标签链接使用 `/articles?tag=<slug>`。

## 首页个人卡

个人介绍与原 About 页面合并为一张服务端渲染的双面卡片：

- 正面：头像、昵称、短简介、状态与主要社交入口
- 背面：完整介绍、站点信息与更多联系方式

翻转必须支持鼠标、触摸、Enter 和 Space，并通过 `aria-expanded` 表达状态。启用 `prefers-reduced-motion` 时取消三维动画。

## 内容类型

### 文章

长篇内容，具有修订、摘要、封面、分类、标签、草稿和定时发布能力。

### 动态

替代“随记”，用于短内容和日常状态。支持 Markdown、可选媒体、可选心情、草稿、公开与私密状态，并拥有稳定链接。

文章和动态是两种独立内容模型，不通过长度互相转换。

## 订阅

RSS 首批提供：

- `/feed.xml`：全部公开更新
- `/feeds/articles.xml`：文章
- `/feeds/dynamics.xml`：动态

邮件订阅支持分别订阅文章、动态或摘要。订阅邮箱保持私密，使用双重确认和可撤销的哈希令牌。内容发布只写入 outbox，由后台任务异步发送邮件。

## 可配置界面

管理后台允许配置：

- 调色板与语义设计 token
- 字体、间距、圆角和动效等级
- 首页已注册组件的显示、顺序和有限布局
- 个人卡正反面内容
- 导航入口和页脚内容

第一阶段不提供任意 HTML、CSS 或脚本编辑器，避免配置系统演变为不可验证的代码注入入口。
