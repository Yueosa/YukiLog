# LianMarkup 语法速查

一页查完所有语法。完整定义见 [语法规范.md](./语法规范.md)

## 块级

| 写法 | 效果 |
|-|-|
| `# 标题` ~ `###### 标题` | 一到六级标题, `#` 后必须有空格 |
| `## 标题 {#id}` | 自定义锚点 |
| `@toc depth=3` | 目录指令, 不产生正文 |
| `> 引用` | 引用块, 空行结束 |
| `>?` `>!` `>+` `>x` `>i` | callout: 疑问/警告/提示/反例/信息, 首行标题, 空行结束 |
| `>>>` 标题 ... `<<<` | 折叠块(显式配对) |
| `>>>` 标题 + TAB 缩进内容 | 折叠块(缩进作用域) |
| `>>>+` | 默认展开的折叠块 |
| ` ```rust ` | 围栏代码块 (服务端高亮) |
| ` ```mermaid ` / ` ```diff ` | mermaid 图表 / diff 增删视图 (集成层增强) |
| `~~~` | 原样块, 内部零解析 |
| `:::` | 示例块: 一份源码, 原文+效果双栏 |
| `-` / `1.` / `- [ ]` / `- [x]` | 无序/有序/任务列表, TAB 嵌套 |
| `| a | b |` | 管道表格 |
| `---` / `___` | 轻分割线 / 幕间转换线 (重分割) |
| `// 注释` | 注释行, 不渲染 |
| 文件顶部 `---` 包围的 YAML | front matter, 仅导入工具用 |

## 行内

| 写法 | 效果 |
|-|-|
| `**粗**` `*斜*` `***粗斜***` `~~删~~` `==高亮==` | 基础样式 |
| `` `代码` `` | 行内代码, 内部不解析 |
| `[文字](url)` | 链接 |
| `[文字]{.类名 k=v}` | 行内容器: lm- 类 span, 参数变 CSS 变量 |
| `![alt](src){width=60% group=组名}` | 图片 + 可选属性 |
| `[^备注内容]` | 旁注, 就地书写 |
| `||剧透||` | 点击显示 |
| `$E=mc^2$` / `$$...$$` | 行内/块级公式 (LaTeX) |
| `{漢字|かんじ}` | 注音, `\|` 转义竖线 |
| `\*` | 转义, 仅对语法符号生效 |

## 三条保命规则

1. **行首关键字后必须有空格**, 否则是正文 (`#这` 是文本)
2. **行内定界符必须成对且内容非空**, 否则回退为文本 (`2*3=6` 没事)
3. 原样区域优先于转义: 行内用 `` ` ``, 块级用 `~~~`, `\` 是最后手段
